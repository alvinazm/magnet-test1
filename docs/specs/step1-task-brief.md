## 四、具体任务要求

> 培训文档要求:1—5 条,每条 20—50 字,只写一件事,只写结果,不写操作教程。

1. 完成 6 个渠道的规模、毛利、费用效率与投放回报分析,给出增投、维持或收缩的方向与依据。
2. 完成 42 家门店的坪效、租售比与 O2O 履约分析,按策略标准分级并逐家给出调整建议。
3. 评估 50 个促销活动的类型分布与投入产出效果,给出 2026H2 促销组合与投放节奏建议。
4. 分析 2,500 名会员的渠道分布、复购与跨渠道行为,给出会员运营与渠道协同建议。
5. 汇总形成 2026H2 预算、人力与营销资源的再分配方案与执行优先级,并披露数据异常与待核事项。

(5 条,均在 27—45 字区间;只写"做什么",不写"怎么做")

## 五、任务范围与口径

> 培训文档要求:只填写不写就会改变结论的时间、对象、边界、计算口径或适用标准。

### 5.1 时间口径

| 项 | 取值 |
| --- | --- |
| 数据回顾期 | 2026-01-01 至 2026-06-30 |
| 建议执行期 | 2026-07-01 至 2026-12-31(2026H2) |
| 基准日 | 2026-06-30 |

### 5.2 对象范围

| 项 | 取值 |
| --- | --- |
| 渠道 | 6 个线上销售/履约渠道 |
| 门店 | 集团下属 42 家在营门店(华东 18、华南 12、华北 12) |
| 品类与商品 | 6 个一级品类、200 个 SKU |
| 会员 | 2,500 名注册会员 |
| 促销活动 | 50 个 H1 已开展活动 |

### 5.3 收入与费用口径

| 维度 | 字段 | 说明 |
| --- | --- | --- |
| 渠道销售 | `净收入` | 收入 − 退款 |
| 门店到店销售 | `到店销售额` | 仅顾客到店完成交易的部分 |
| 门店 O2O 履约贡献 | `门店O2O履约贡献` | 由渠道明细中"门店发货 + 到店自提"订单按门店聚合 |
| 门店履约单量 | `线上订单履约单量` | 自提单量 + 门店发货单量;快递订单不关联门店、不计入门店履约 |
| 门店总费用 | `租金及物业费 + 人力 + 营销 + 水电 + 履约包装 + 其他 + 折旧摊销` | 不含线上履约费(该费用归渠道) |

### 5.4 面积调整口径

- 计划期内发生面积调整的门店,在门店台账中以 `面积是否调整 = 是` 标识
- 该类门店按当前面积计算的坪效口径可能失真,需在《异常与待核清单》中披露

### 5.5 货币与精度

- 所有金额单位为人民币元(¥),保留两位小数
- 比例字段统一为小数(0–1),百分比自行换算
- 客单价、坪效等单价指标保留整数

### 5.6 异常披露原则

- 数据冲突、口径不清、材料不足时,允许披露、待补、缩小范围、条件交付或给出负向结论
- 所有披露事项须在《异常与待核清单》中列明,并说明影响范围与建议处理方式
- 不在《异常与待核清单》之外的任何位置对异常保持沉默
