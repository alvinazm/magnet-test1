   美团闪购)的销售规模、毛利贡献、费用效率、依赖度与投放 ROI 评估,

## 三、对象、范围与时间

```
对象范围:
  - 集团下属 42 家在营门店(覆盖华东、华南、华北三个区域)
  - 6 个线上销售/履约渠道(自营 APP、微信小程序、天猫、京东、抖音、美团闪购)
  - 集团 2,500 名注册会员与 50 个促销活动
  - SKU 主数据(200 个 SKU,跨 6 个一级品类)

时间口径:
  - 数据回顾期:2026-01-01 至 2026-06-30(2026H1,完整半年)
  - 建议执行期:2026-07-01 至 2026-12-31(2026H2,完整半年)
  - 基准日:2026-06-30
  - 所有比较分析(如费用率、毛利率)需明确分母与期间,不得跨期混用

关键主键(跨附件核对):
  - 门店ID:门店台账 ↔ 渠道销售明细(履约门店)↔ 会员订单(履约门店)↔ 租约汇总

  - 会员ID:会员基础 ↔ 会员订单 ↔ 跨渠道行为
  - 活动ID:活动清单 ↔ 活动明细 ↔ 活动效果

单位与精度:
  - 货币:人民币元(¥),保留两位小数
  - 比例:统一为小数(0-1),百分比自行换算
  - 客单价、坪效等单价指标:保留整数
```

## 五、规则与口径

```
所有专业判断必须以《渠道与门店管理策略.docx》(附件《渠道与门店管理策略.docx》)的以下规则为依据。
请先完整阅读该文档,理解后再开始分析。

【门店分级标准 - 附件《渠道与门店管理策略.docx》 第 2 章】
  - A 级:到店坪效 ≥ 5,000 元/㎡/月,租售比 ≤ 15%
  - B 级:到店坪效 2,000–5,000 元/㎡/月,租售比 15%–25%
  - C 级:到店坪效 1,000–2,000 元/㎡/月,租售比 25%–35%
  - D 级:到店坪效 < 1,000 元/㎡/月 或 租售比 > 35%
  注:坪效与租售比是两个并列指标,任一触发 D 级阈值即降级。

【O2O 履约规则 - 附件《渠道与门店管理策略.docx》 第 3 章】
  - 门店发货、到店自提订单计入线上渠道收入,同时按归属计入门店"门店 O2O 履约贡献"。
  - 即时配送订单归属即时零售渠道,履约成本由渠道承担。
  - 门店仅承担履约侧的人工与包装成本(对应"门店费用.履约包装")。

【数据来源优先级 - 附件《渠道与门店管理策略.docx》 第 4 章】
  - 财务确认收入优先于业务系统数据。
  - 冲突时以"渠道销售明细"和"门店台账"交叉验证。
  - 无法确认时标记"待补",不得用假设补齐事实。

【闭店与改造条件 - 附件《渠道与门店管理策略.docx》 第 6 章】
  - 租约到期且连续 6 个月 D 级,可启动闭店评估。
  - 租售比连续 3 个月 > 35%,可转为前置仓或自提点。
  - 面积调整门店不计入同店口径(本任务中以"是否同店口径=否"标识)。

【来源规则】
  - 不得使用本题未提供的其他渠道的内部政策、阈值、评分标准替代附件《渠道与门店管理策略.docx》 的规则。
  - 不得使用外部数据(如行业平均、竞品数据)替代题内材料得出结论。
  - 在合理专业判断范围内,允许你基于附件数据自行定义补充指标(如"渠道毛利贡献占比"),
    但需在《异常与待核清单》中披露定义方法。
```

## 六、缺失与异常处理

```
【允许的处理方式 - 必须严格遵守】
  - 披露:对数据冲突、口径不清、规则未覆盖的情况,在《异常与待核清单》
    中明确披露,并说明影响范围。
  - 待补:对题内材料不足以得出确定结论的事项,标记"待补"并指出所需补全信息。
  - 缩小范围:在不影响核心交付的前提下,可将分析范围缩小至明确可解的子集。
  - 条件交付:在某些前提下成立、在其他前提下需要修正的结论,需明确前提。
  - 局部交付:某些交付物的部分内容因数据缺失无法完成,可分模块交付。
  - 负向结论:数据不支持继续某项业务时,可明确建议收缩/退出,不得
    用假设、估算或类比维持正面结论。

【不允许的处理方式 - 严格禁止】
  - 不得虚构事实、金额、姓名、店名、活动效果等任何数据。
  - 不得用假设补齐缺失(如"假设毛利率提升至 X%,则...")。
  - 不得用行业平均、竞品数据或外部研究替代题内材料。
  - 不得在《异常与待核清单》之外的任何位置对异常保持沉默。
  - 不得为追求"完整答案"而编造附件中不存在的统计或趋势。

【跨文件数据冲突的处理示例】
  - 若"渠道销售明细"与"会员订单"对同一订单号金额不一致:
    以"渠道销售明细"的"成交价"为准,会员订单侧记入异常清单。
  - 若"门店月度经营"的到店销售额与通过"门店费用 + 渠道 O2O 贡献"
    反推的口径不一致:
    以"门店月度经营"的"到店销售额"为准,反推口径作为异常披露。
  - 若租约 PDF 的租金与"门店费用"的月租金不一致:
    以"门店费用"实际发生金额为准,租约 PDF 标注为参考值。
```

## 八、专业难度注入说明

```
本任务的设计刻意注入了以下 5 类专业难度,期望你的工作体现专业判断:

1. 【跨源处理 - 主键与口径】
   同一门店在"门店台账"与"渠道销售明细"中以"门店ID"关联,但其
   "到店销售额"与"门店 O2O 履约贡献"是独立维度,需正确理解并分维度
   分析;同一订单可能在"渠道销售明细"和"会员订单"中重复出现,需
   通过订单号去重;同一 SKU 的成本在"SKU 主数据"与"渠道销售明细.
   商品成本"中一致,需通过 SKU 编码验证。

2. 【多步骤计算 - 勾稽与复算】
   渠道 P&L(净收入 - 平台佣金 - 广告费 - 履约费 - 其他费用)→
   渠道毛利率与销售费用率 → 渠道资源调整建议;门店到店坪效(到店销售
   ÷ 营业面积)与租售比(月租金 ÷ 到店销售额)→ 门店分级 → 调整建议;
   促销 ROI(增量毛利 ÷ 实际费用)→ 促销类型取舍 → H2 节奏。每一步的
   结果会进入下一步,前一步错误会导致后续判断全部失效。

3. 【专业判断 - 规则应用与例外处理】
   按附件《渠道与门店管理策略.docx》 的门店分级标准,需同时满足坪效与租售比;同店口径需排除
   3 家面积已调整门店(S006、S013、S031);促销 ROI 计算需正确选
   择分母(增量毛利 vs 增量销售额);租约到期门店需结合"闭店条件"
   计算真实关店成本。

4. 【异常处置 - 数据真实性核查】
   跨表数值不一致、SKU 主数据缺失、价格异常、退款率过高等情况需主动
   发现并披露;对"旧版门店清单_2024.xlsx"需识别其与当前任务(2026H1)
   的时间口径差异,不将其作为当前数据使用。

5. 【交付组织 - 多文件口径一致】
   5 个交付物之间的门店数、渠道数、SKU 数、会员数、金额合计必须完全
   一致;同一指标(如"净收入")在各交付物中使用相同字段名与相同口径;
   关键数字在 Strategy Report 与 Excel 之间能相互追溯。
```

- 指令遵循:5 个交付物是否齐全,格式与必含字段是否符合
- 格式:文件结构、字段命名、章节位置、Sheet 划分是否合理
- 语气与沟通:是否区分事实/判断/建议,是否使用了恰当的表达

你的工作将被 3 家不同生产结果的横向对比评估。
请独立完成,不要试图揣测"标准答案",而是基于附件做严谨的专业判断。
