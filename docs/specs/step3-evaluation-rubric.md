## 一、A 模块字段说明

每条 A 标准包含 5 个字段:

| # | 字段 | 来源 | 填写要求 |
| --- | --- | --- | --- |
| 1 | **序号** | 自定义 | A-1, A-2, ... 连续编号 |
| 2 | **标准描述** | 6.4 节 | 「依据 + 检查什么 + 合格条件 + 必要边界」四要素 |
| 3 | **类型** | 6.3.1 节 | 结果正确性 / 专业质量 / 指令遵循 / 格式 / 语气与沟通(5 选 1) |
| 4 | **影响程度** | 6.3.3 节 | 关键 / 重要 / 一般(看不满足的业务后果) |
| 5 | **是否有中间状态** | 6.3.2 节 | 无(二元判断)/ 有(存在部分完成水平) |
| 5b | **中间状态档位** | 6.3.2 节 | 选「有」时填 2–4 档,结构化表格,逐级递进、高档含低档 |

**类型判断口径**(6.3.1 节):按"修好它主要需要改什么"判断——改数字/计算 → 结果正确性;改方法、证据链、专业边界 → 专业质量;补做题面明确要求但漏掉的工作 → 指令遵循;只改文件结构/字段位置 → 格式;只改表达方式 → 语气与沟通。

## 三、结果正确性(A-1 ~ A-6)

### A-1 · 渠道净收入、毛利与毛利率可由材料复算

**标准描述**

```
依据 Query 第 1 章"渠道规模、毛利、费用效率"要求,以及附件《2026H1渠道销售明细.xlsx》
     渠道月度汇总 Sheet(收入/退款/净收入/商品成本/订单量/毛利/客单价);
检查 6 个渠道的净收入、毛利、毛利率、客单价是否由材料严格复算得出;
合格条件 净收入 = 收入 − 退款;毛利 = 净收入 − 商品成本;毛利率 = 毛利 ÷ 净收入;
         客单价 = 净收入 ÷ 订单量;6 个渠道逐渠道给出,且合计与渠道销售明细的订单级汇总一致;
必要边界 不得用"约 X 万元"等模糊表述;不得把收入与净收入混用;
         不得引用材料之外的行业基准或竞品数据。
```

| 字段 | 值 |
| --- | --- |
| 类型 | 结果正确性 |
| 影响程度 | **关键**(渠道盈亏与资源方向的核心金额,错误会直接改变 H2 分配结论) |
| 是否有中间状态 | **有** |

**中间状态档位**

| 档位 | 标签 | 描述 |
| --- | --- | --- |
| 第 1 档 | 不满足 | 6 个渠道中有 ≥2 个渠道未给出净收入、毛利、毛利率、客单价中的任一指标,或这 4 项指标中任一与材料复算偏差 > 5%。 |
| 第 2 档 | 部分满足 | 在上一档基础上,6 个渠道的净收入、毛利、毛利率、客单价均已给出且与材料复算偏差 ≤ 5%;但其中 1–2 个渠道存在收入与净收入口径混用,或合计与订单级汇总不一致。 |
| 第 3 档 | 满足 | 在上一档基础上,6 个渠道的净收入、毛利、毛利率、客单价与《2026H1渠道销售明细.xlsx》逐渠道逐月复算完全一致(误差 ≤ 0.01 元),口径统一为净收入,合计与订单级汇总一致。 |

### A-2 · 渠道费用效率与投放回报口径正确

**标准描述**

```
依据 Query 第 1 章"各类渠道费用、费用效率与投放回报"要求,附件《2026H1线上投放与平台费用.xlsx》
     渠道月度费用 Sheet、投放明细 Sheet、平台佣金规则 Sheet,以及附件《渠道与门店管理策略.docx》第 7 章;
检查 渠道费用合计、销售费用率、投放 ROI 是否按附件口径计算;
合格条件 费用合计 = 广告费 + 平台佣金 + 技术服务费 + 支付手续费 + 履约费 + 包装费 + 退货售后费 + 其他费用;
         销售费用率 = 费用合计 ÷ 净收入;
         投放 ROI = 投放明细.支付金额 ÷ 投放金额;
         平台佣金可由「平台佣金规则」Sheet 按"渠道 × 品类收入 × 该品类佣金率"逐项复算;
必要边界 不得用毛利代替净收入作费用率分母;不得用单一平均费率倒算分品类佣金;
         不得把估算或建议值表述为实际发生额。
```

| 第 3 档 | 满足 | 在上一档基础上,8 项费用分项与费用合计逐渠道一致,平台佣金按"渠道 × 品类收入 × 佣金率"逐项复算偏差 ≤ 0.01 元,销售费用率与投放 ROI 可由材料完整复算。 |

```

检查 42 家门店是否全部给出 A/B/C/D 级别,且级别与附件阈值一致、没有无法归类的门店;

### A-5 · 到店销售与门店 O2O 履约贡献分维度核算

**标准描述**

```
依据 附件《渠道与门店管理策略.docx》第 3.1、3.3、3.5、3.6 条,以及附件《2026H1渠道销售明细.xlsx》
     渠道销售明细 Sheet(发货方式/净收入/门店ID);
检查 生产结果是否将"到店销售额"与"门店 O2O 履约贡献"分别核算、分别体现;
合格条件 门店 O2O 履约贡献 = 发货方式 ∈ {门店发货, 到店自提} 的订单净收入按门店聚合;
         快递订单不关联门店、不计入门店履约贡献;
         两部分不得直接相加后做毛利率分析;
         O2O 履约贡献可由材料复算(误差 ≤ 0.01 元);
必要边界 即时配送订单归属即时零售渠道、履约成本由渠道承担,不计入门店 O2O 履约贡献;
         门店履约单量 = 自提单量 + 门店发货单量,不含快递订单。
```

**标准描述**

```

         若自行设定 ROI 建议阈值,须在《异常与待核清单.xlsx》披露定义方法。

| 档位 | 标签 | 描述 |
| --- | --- | --- |
| 第 1 档 | 不满足 | 超过 50% 的关键表述把建议或估算写成既定事实,或使用"必须/一定"等绝对词,且投入金额未标注建议性质。 |
| 第 2 档 | 部分满足 | 在上一档基础上,≥80% 的关键表述可区分事实、判断与建议;但 1–2 处建议值未标注性质,或仍存在模糊修饰词。 |
| 第 3 档 | 满足 | 在上一档基础上,全部关键表述区分清楚,投入类建议均标注建议值或条件性方案及前提,无绝对词与模糊修饰。 |
