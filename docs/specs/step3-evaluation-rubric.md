## 一、A 模块字段说明(培训文档 6.3 节)

每条 A 标准包含 **5 个字段**:

| # | 字段 | 来源 | 填写要求 |
| --- | --- | --- | --- |
| 1 | **序号** | 自定义 | A-1, A-2, ... |
| 2 | **标准描述** | 6.4 节 | "依据 + 验收对象 + 合格条件 + 必要边界" 四要素结构 |
| 3 | **类型** | 6.3.1 节 | 结果正确性 / 专业质量 / 指令遵循 / 格式 / 语气与沟通(5 选 1) |
| 4 | **影响程度** | 6.3.3 节 | 关键 / 重要 / 一般(看"不满足造成的业务后果") |
| 5 | **是否有中间状态** | 6.3.2 节 | 无(只能二元判断)/ 有(存在部分完成水平) |
| 5b | **中间状态档位**(选填) | 6.3.2 节 | **2-4 档,从低到高,高档含低档要求** |

### 1.1 中间状态档位写法规范(v1.3 结构化表格)

按培训文档 6.3.2 节,采用**结构化表格**写法,每档独立一行,便于机审按"档位 N 描述"独立字段读取:

| 档位 | 标签(可选) | 描述 |
| --- | --- | --- |
| 第 1 档 | 不满足 | [基础缺失条件] |
| 第 2 档 | 部分满足 | 在上一档基础上,加 [第一层要求] |
| 第 3 档 | 满足 | 在上一档基础上,加 [最高要求] |

要点(培训文档 6.3.2 节):
- **逐级递进**:升一档需要多满足一项清楚的条件
- **高档含低档**:第 N 档必须包含第 N-1 档的全部要求
- **可观察**:用数字阈值(数量/比例)划分
- **不重叠**:一个表现不能同时落入两档
- **无空档**:相邻档位首尾衔接

### 1.2 标签说明

"不满足 / 部分满足 / 满足"是培训文档示例使用的标签名称(L435、L511),非强制。
- 如果实际机审系统按"档位 1/2/3"读取:忽略标签,只读描述列
- 如果按"不满足/部分满足/满足"读取:标签列就是答案
- 两种场景都兼容

### A-1 · 渠道净收入与毛利率计算

**标准描述**

```
依据 附件《2026H1渠道销售明细.xlsx》渠道销售明细 Sheet 和 渠道月度汇总 Sheet,
检查 6 个渠道的净收入、毛利、毛利率、客单价是否由公式严格计算得出;
合格条件 净收入 = SUM(收入) − SUM(退款金额),
         毛利 = SUM(收入) − SUM(退款金额) − SUM(商品成本),
         毛利率 = 毛利 ÷ 净收入,
         客单价 = 净收入 ÷ 订单量;
         6 个渠道各自计算且合计与全渠道月度汇总一致;
必要边界 不含未在附件中出现的数据源;
         不接受"约 X 万元"等模糊数字,需保留两位小数并可由附件复算。
```

### A-3 · 门店分级遵循坪效定级与租售比否决

**标准描述**

```
依据 附件《渠道与门店管理策略.docx》第 2 章门店分级标准(2.1–2.3 条),
检查 A/B/C/D 各级门店的判定是否按附件阈值执行,且无"无法归类"的门店;
合格条件 按到店坪效分级:A 级 ≥ 5,000 元/㎡/月;B 级 2,000–5,000 元/㎡/月;
         C 级 1,000–2,000 元/㎡/月;D 级 < 1,000 元/㎡/月;
         租售比 > 35% 的门店不参与上述分级,直接列为 D 级;
         42 家门店必须全部给出 A/B/C/D 级别,不允许出现"未分级"；
```
