## 二、业务背景

```
2026 年上半年,公司在 6 个线上渠道(自营 APP、微信小程序、天猫、京东、抖音、美团闪购)实现多渠道规模化销售,门店同时承担线上订单履约与到店销售职能。当前业务呈现"渠道集中度高、门店整体微亏、投放成本占比偏高"的结构性特征,管理层需要在 8 月初 H2 战略复盘会前确定下半年资源分配方向,直接关系到 Q3、Q4 的销售目标达成与全年盈利水平。
```

(约 200 字,满足 ≥ 60 字要求)

## 三、任务目的

```
基于 2026H1 经营数据(渠道销售、门店台账、投放与费用、会员订单、促销活动、门店租约、渠道制度、SKU 主数据),完成 6 个渠道与 42 家门店的结构诊断与异常识别,形成 2026H2 渠道资源再配置、门店分级调整与促销组合优化的具体建议,支撑集团管理层下半年的预算、人力、营销资源分配决策。
```

## 四、具体任务要求

> 培训文档要求:1—5 条,每条 20—50 字,只写一件事,只写结果,不写操作教程。

### 1. 渠道结构诊断与资源调整建议

完成 6 个渠道(自营 APP、微信小程序、天猫、京东、抖音、美团闪购)的销售规模、毛利贡献、费用效率与依赖度分析,识别增投、维持、收缩的渠道并给出依据。

### 2. 门店经营诊断、分级与调整建议

完成 42 家门店的规模、坪效、租售比、O2O 履约贡献分析,基于《渠道与门店管理策略》分级标准形成 A/B/C/D 分级,逐家给出保留、调改、关停或转型建议。

### 3. 促销组合效果评估与节奏优化

评估 50 个促销活动的类型、渠道分布与 ROI,识别高效与低效促销,给出 2026H2 促销类型保留、调整与新增的具体建议。

### 4. 会员跨渠道行为与协同机会识别

分析 2,500 名会员在多渠道的注册、复购、流失与跨渠道购买行为,识别渠道协同价值与渠道蚕食风险,给出会员运营建议。

### 5. 资源再配置方案与异常披露

汇总形成 2026H2 预算、人力、营销资源的再分配方案与执行优先级;同时披露数据异常、口径冲突与待核事项,不得虚构事实。

(5 条,均在 30–45 字范围,只写"做什么",不写"怎么做")

## 五、任务范围与口径

### 5.1 时间口径

| 项 | 取值 |
| --- | --- |
| 数据回顾期 | 2026-01-01 至 2026-06-30 |
| 建议期 | 2026-07-01 至 2026-12-31(2026H2) |
| 基准日 | 2026-06-30 |

### 5.2 对象范围

| 项 | 取值 |
| --- | --- |
| 门店 | 集团下属 42 家在营门店 |
| 渠道 | 6 个线上销售/履约渠道 |
| 区域 | 华东、华南、华北三个区域 |
| 会员 | 2,500 名注册会员 |

### 5.3 收入与口径

| 维度 | 字段 | 说明 |
| --- | --- | --- |
| 渠道销售 | `净收入` | 收入 − 退款 |
| 门店到店销售 | `到店销售额` | 仅顾客到店完成交易的部分 |
| 门店 O2O 履约贡献 | `门店O2O履约贡献` | 从渠道聚合,反映门店作为履约节点的价值 |
| 门店总费用 | `租金 + 人力 + 营销 + 水电 + 履约包装 + 其他 + 折旧摊销` | 不含 O2O 履约的线上履约费(该费用归渠道) |

### 5.4 同店口径

- 同店增长率计算需**排除** `是否同店口径 = 否` 的 3 家门店(S006、S013、S031)
- 排除原因:**面积已调整**,不具有可比性(详见《华东区门店租约汇总》备注)

### 5.5 货币与精度

- 所有金额单位为人民币元(¥),保留两位小数
- 比例字段统一为小数(0–1),百分比自行换算
- 客单价、坪效等单价指标保留整数

### 5.6 异常披露原则

- 数据冲突、口径不清、租约未确定时,允许披露、待补、缩小范围、条件交付或负向结论
- **不得**用假设、估算或外部数据补齐事实
- 所有披露事项需在《异常与待核清单》中列明
