> **来源**:M3 《异常与待核清单.xlsx》`A-006`;本次核查独立复算并补充口径澄清

| 项 | 内容 |

| **制度原文(引文照录)** | "3.1 门店发货、到店自提订单计入线上渠道收入,同时按发货/自提归属计入门店履约贡献。""3.2 即时配送订单归属即时零售渠道,履约成本由渠道承担,门店作为履约节点。""3.4 门店发货、到店自提、即时配送订单必须关联门店ID;快递订单不关联门店ID。" |
| **术语与编号的对应(本次确认)** | "即时零售渠道"即 **CH06 美团闪购**,由材料字段 `渠道类型` 唯一支撑:`自营` = CH01 自营APP、CH02 微信小程序;`平台` = CH03 天猫旗舰店、CH04 京东自营、CH05 抖音小店;**`即时零售` 仅 CH06 一家** |
| **两个字段各管一件事(规则澄清)** | ①**收入、退款、商品成本、各项费用归哪个渠道,只看 `渠道ID`(下单渠道),与 `发货方式` 无关**;②`发货方式` 只决定"是否计入门店 O2O 履约贡献"(`门店发货`、`到店自提` 计入,`即时配送`、`快递` 不计入,但即时配送仍须关联门店) |
| **数据现状(复算证据)** | 按 `发货方式` = 即时配送 统计:CH06 **554 单**/178,027 元、CH05 161、CH03 147、CH01 68、CH02 67、CH04 38 → **非 CH06 合计 481 单**、406,886 元,占各渠道净收入 3.5%(CH04)～11.2%(CH01);示例订单 `O100021`(下单 CH05 抖音小店、即时配送、门店 S041)现按 CH05 归集收入与履约费 |
| **歧义点** | 第 3.2 条用"**订单归属**即时零售渠道"的措辞,且未说明它与 3.1 条"按渠道归集"的关系。若按字面读作"收入也归 CH06",则 **1,035 单**即时配送应全部计入 CH06;而数据只把其中 554 单放在 CH06,其余 481 单仍在下单渠道 |
| **影响(两种口径的规模差)** | 按现数据(下单渠道):CH06 净收入 **238,360.01 元**(六渠道最小);若即时配送全归 CH06:CH06 → **645,245.94 元**(+406,885.93,超过 CH02),CH01/CH02/CH03/CH04/CH05 分别减少 77,663.02 / 44,487.79 / 136,909.95 / 40,900.62 / 106,924.55 元。渠道规模排序、集中度、费用率(含按渠道收入计提的 `履约费`)与报告第 1 章的渠道方向建议均随之变化 |
| **因材料冻结的处理方式** | 按任务书第五节【允许的处理方式·披露】与【条件性结论与事实边界】执行:①交付物须在《异常与待核清单.xlsx》披露该口径歧义,写明**本次分析采用的口径**("订单收入与费用一律按下单渠道确认")及其理由(与第 3.1 条按渠道归集一致、数据自洽);②给出另一口径下的规模差异量级(CH06 约 23.8 万元 vs 64.5 万元);③**不得**把"即时配送订单的收入归属即时零售渠道"写成已确认事实,也不得据此重排渠道规模 |
| **建议条款文本(供下一版本材料使用)** | 第 3.2 条改为:"即时配送是履约方式(与快递、门店发货、到店自提并列),不改变收入与费用的渠道归属。订单的收入与费用一律按下单渠道(`渠道ID`)确认:通过即时零售渠道下单的计入即时零售渠道(CH06 美团闪购),经其他渠道下单的计入对应下单渠道;履约成本按承担履约的门店所属的下单渠道核算。" 并在第 1.3 条补一句映射:"即时零售渠道对应材料中的 CH06(美团闪购)" |

### M-02 `销售费用率` 未在制度中定义【低】

> **来源**:M3 《异常与待核清单.xlsx》`A-011`;本次核查独立复算确认

| 项 | 内容 |
| --- | --- |
| 定位 | `docs/specs/step2-query.md` 交付物 3(渠道资源再配置建议)的必含字段 `销售费用率` ↔ `input/渠道与门店管理策略.docx`(第 1–9 章全文检索无"销售费用率") |
| 复算证据 | 材料可支撑的自然定义为"渠道费用合计 ÷ 净收入",实测 6 渠道区间 **13.8%(CH02)～37.8%(CH05)**;制度未给出任何定义 |
| 影响 | 交付物 3 的必含字段缺少制度依据,不同产物可能选用不同分母(收入或净收入),同一渠道出现两个费用率 |

| 建议条款文本(供下一版本材料使用) | 在《渠道与门店管理策略.docx》第 7 章补一条:"7.7 销售费用率 = 渠道费用合计 ÷ 净收入,用于渠道间费用效率比较;分母为净收入,不得以收入替代。" |
