## 五、本轮沉淀的四条元层面教训

1. **模型异常清单必须逐条独立复算再采信**:M3 的 16 条里 1 条是误报(A-004),若不复核就写进材料问题清单,
   会把"模型误判"当成"材料缺陷"传递给下一环节。判定要点:**先用材料自身的字段语义定义去验,再质疑材料**。
2. **"分项 + 合计"要自校验**:A-006 的三处分项全对、合计却错(549 vs 481)——单看分项发现不了,
   必须做一次加总校验,这类错误在报告正文里同样会出现。
3. **许可性条款的触发条件是"历史事实"**:制度里的"连续 N 个月""累计达到"等条件一旦满足即为已触发;
   以"当期回落"推翻触发条件(S028)会让处置方向偏离制度,应在依据中写明"已触发但选择不采用"的理由。
4. **规范类问题在产物侧仍普遍存在**:本轮 M3 的 137 + 18 处引用不规范,与之前的产物同因——
   依据必须写成"完整文件名 + 扩展名 + Sheet + 字段",否则评审无法定位。
